# tsw-dn-assets

Built scripts for [tshirtworkshop.com.au](https://www.tshirtworkshop.com.au) (Tshirt Workshop, Wollongong), served by
[jsDelivr](https://www.jsdelivr.com), with GitHub Pages as the backup.

The files in `builds/` are generated from a private source repository and aren't edited here. Each build keeps its own
name, so pages that are already open keep working when a new build is published.

`halftone/` is the DTF Halftone staff tool: one page that turns artwork into halftone PNGs for DTF film. The art is
processed in the browser and never uploaded.
